# Campus Flow

아이캠퍼스에서 복사한 iCalendar(ICS) 피드 주소를 연결하면 마감 일정을 **오늘**과 **이번 주**로 나누어 보여주는 웹앱입니다.

## 실행

Node.js 18 이상에서 아래 명령을 실행하세요.

Windows에서는 `start-campus-flow.cmd` 파일을 더블클릭하면 서버 실행과 브라우저 열기가 자동으로 진행됩니다. 열리는 검은 창은 사이트를 사용하는 동안 닫지 마세요.

터미널에서 직접 실행하려면 아래 명령을 사용합니다.

```bash
npm start
```

브라우저에서 `http://localhost:4173`을 열면 됩니다. 별도 패키지 설치는 필요하지 않습니다.

## 사용

1. 아이캠퍼스(Canvas)의 캘린더/일정 메뉴에서 캘린더 피드(ICS 또는 webcal) 주소를 복사합니다.
2. Campus Flow의 **캘린더 연결**을 누르고 주소를 붙여 넣습니다.
3. 오늘 마감과 이번 주 마감 일정이 자동으로 분류됩니다.

일반 `https://...ics` 주소, `webcal://...ics` 주소, `[주소](주소)` 형태로 복사된 링크를 모두 붙여 넣을 수 있습니다. 반드시 `npm start`로 서버를 실행하고 `http://localhost:4173`에서 접속해야 합니다. HTML 파일을 직접 열거나 VS Code Live Server로 열면 외부 캘린더를 불러올 수 없습니다.

피드 주소와 불러온 일정 캐시는 해당 브라우저의 로컬 저장소에 저장됩니다. 서버는 요청 시 피드를 전달할 뿐 주소를 따로 저장하지 않습니다.
